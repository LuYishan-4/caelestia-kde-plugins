# Ultralight Web Cursor Settings

Quickshell settings UI for the `web-cursor` KWin effect. It registers the
`Meta+Shift+C` shortcut and manages the shared `webCursor` configuration in
`~/.config/caelestia/shell.json`.

Install `web-cursor` first. The two plugins must remain installed as sibling
directories in Caelestia's plugin directory so this UI can build and install
the effect when required.
